# 个人电子名片（GitHub Pages 静态站点）

一个纯前端、无需构建工具、无需后端的 vCard 电子名片页面。所有信息在 `index.html` 顶部的 `PRESET_CARD` 配置对象里修改，部署后扫码即可打开。

## 已实现的功能

- **资料展示**：头像（首字母占位）、姓名、公司 / 职位、个人简介、渐变主题配色
- **悬停切换 + 点击固定**：头像、姓名、简介都可设置备选图片/文字。鼠标悬停时淡入备选内容，移开恢复；点击后固定为备选内容，再点一次恢复原状，带 0.35s 淡入淡出过渡
- **快捷操作**：拨打电话、发送邮件、跳转导航（字段为空时自动隐藏对应按钮）
- **联系信息**：生日、手机、办公电话、传真、邮箱、个人网站、地址，逐项条件展示
- **社交渠道**：可配置多个外链（X、Telegram、WhatsApp、Facebook、Instagram、LinkedIn、YouTube、TikTok）
- **保存名片**：
  - 下载标准 vCard 文件（`.vcf`，可直接导入手机通讯录）
  - 复制整份名片资料为文本
  - 通过邮件发送名片内容（`mailto:`）
- **分享页面**：Facebook、X、WhatsApp、邮件、复制链接、系统原生分享（Web Share API，不支持时回退为复制链接）
- **位置导航**：Google 地图嵌入预览 + 跳转 Google Maps 路线规划
- **页面二维码**：根据当前页面地址自动生成二维码，手机扫码打开本页
- **页面内编辑**：进入编辑模式后直接点文字修改，可保存到浏览器本地、导出 HTML、还原默认
- **响应式**：手机优先布局，桌面端居中展示

## 如何修改名片内容

打开 `index.html`，找到 `<script>` 开头的 `PRESET_CARD = { ... }`，按字段填写：

| 字段 | 说明 |
| --- | --- |
| `firstname` / `lastname` | 名 / 姓 |
| `company` / `job` | 公司 / 职位 |
| `bio` | 个人简介，支持换行 |
| `nameHover` | 悬停/点击名字时替换显示的文字；留空则不切换 |
| `bioHover` | 悬停简介时替换显示的文字；留空则不切换 |
| `avatar` | 头像图片路径，如 `assets/avatar.jpg`；留空则显示姓名首字母 |
| `avatarHover` | 悬停头像时替换显示的图片；留空则不切换 |
| `email` | 邮箱 |
| `mobile` / `phone` / `fax` | 手机 / 办公电话 / 传真 |
| `birthday` | 生日，格式 `YYYY-MM-DD` |
| `website` | 个人网站链接 |
| `x` | X 账号，填 `@handle` 或完整链接均可，自动补成 `https://x.com/...` |
| `telegram` | Telegram 账号，填 `@handle` 或完整链接均可，自动补成 `https://t.me/...` |
| `address` | `venue`（机构名）、`street`、`streetNumber`、`city`、`state`、`zip`、`country` |
| `channels` | 其他社交渠道数组，每项 `{ name, link, label }`（X、Telegram 用上面两个字段） |
| `theme.color1` / `theme.color1b` | 头部渐变起止颜色 |
| `theme.showGradient` | 头部是否使用渐变；关闭后为纯色 |
| `theme.bgColor` | 外背景纯色；未设背景图时生效 |
| `theme.bgImage` | 外背景图（URL/路径/上传），铺在卡片外侧；留空用纯色背景 |
| `theme.cardBg` | 内部卡片底色（仅颜色，不支持图片） |
| `splash.enabled` | 是否开启开屏动画 |
| `splash.image` | 开屏展示图；留空则用头像，头像也空时显示首字母 |
| `splash.duration` | 开屏展示时长（秒） |
| `splash.animation` | 动效：`zoom` 缩放、`fade` 淡入、`pop` 弹入、`slide-up` 上滑、`slide-down` 下滑、`rotate` 旋转 |

不需要的字段留空字符串 `""`，页面会自动隐藏对应行，不会显示空占位。

### 新增社交渠道

在 `channels` 数组里加一项即可：

```js
{ name: "Instagram", link: "https://instagram.com/username", label: "关注" }
```

`name` 不区分大小写，内置图标支持：X、Telegram、WhatsApp、Facebook、Instagram、LinkedIn、YouTube、TikTok；未识别的名称会使用通用地球图标。

## 页面内编辑与保存

页面底部「页面编辑」区块提供以下操作：

- **实时状态栏**：编辑表单上方的状态条实时显示当前状态——橙色圆点为「有未保存的修改 · 实时预览中」，绿色圆点为「已保存到本地」。改动会即时反映到名片预览，无需先保存。
- **进入编辑**：展开编辑表单，可直接修改名/姓、公司、职位、简介、悬停名字文字、悬停简介文字、邮箱、网站、X 账号、Telegram 账号、手机、电话、传真、生日、完整地址；头像与悬停头像可上传裁切；还可调整头部渐变起止色、渐变开关、背景颜色、外背景图、卡片底色，以及开屏动画的开关、开屏图、时长和动效。每个图片字段旁有「移除」按钮，可清空已选图片。
- **图片裁切**：头像类上传后弹出裁切框，可拖动、缩放选框；确认后按圆形抠图（圆外透明，输出 400×400 PNG）。外背景图、开屏图直接上传，不做圆形裁切。编辑模式下点击渠道卡片可修改链接。
- **重播开屏**：按当前开屏设置重新播放一次开屏动画，便于预览效果。
- **保存到本地**：把当前修改写入浏览器 `localStorage`，只在你这台设备、这个浏览器生效，其他访问者看不到；保存后状态条变绿。
- **导出 HTML**：把当前配置（含已上传的图片）打包成一份新的 `index.html` 下载到本地。
- **还原默认**：清空本地保存的修改，恢复 `PRESET_CARD` 里的预设内容。

> 本地上传的图片会以 base64 内嵌进页面；图片过大时可能超出浏览器本地存储上限，此时直接「导出 HTML」即可，不影响导出文件。

### 为什么不能一键直接写回仓库

GitHub Pages 是纯静态站点，浏览器里的网页**没有权限直接修改你仓库里的文件**；要做到一键写回，要么需要一个后端服务，要么把 GitHub 访问令牌嵌进网页——公开仓库里放令牌等于把账号权限交给任何人，存在安全风险，因此本项目不采用。

让改动对所有访问者生效的标准流程：

1. 在页面上改好内容，点 **导出 HTML** 下载 `index.html`。
2. 到 GitHub 仓库上传这份文件，覆盖原来的 `index.html` 并提交。
3. Pages 重新部署后，所有人看到的就是新内容。

> 直接改源码时，预设内容位于 `index.html` 里 `CARD_CONFIG_START / END` 注释之间的 `PRESET_CARD` 对象；页面运行时会把本地保存的覆盖项合并到它上面。

## 部署到 GitHub Pages

1. 在 GitHub 新建一个仓库（例如 `digital-card`）。
2. 把 `index.html` 和 `README.md` 上传到仓库根目录。
3. 仓库 **Settings → Pages**，在 **Build and deployment** 中选择：
   - Source：`Deploy from a branch`
   - Branch：`main`，目录 `/ (root)`，保存。
4. 等待约 1 分钟，访问 `https://<你的用户名>.github.io/<仓库名>/` 即可。

页面二维码会自动读取当前线上地址生成；本地 `file://` 打开时二维码内容为本地路径，部署到 Pages 后会自动变成线上地址。

## 说明与限制

- 纯静态实现：vCard 生成、文本复制、分享链接均在浏览器端完成，没有服务器存储任何信息。
- 地图使用 Google Maps 无 Key 嵌入地址；若所在网络无法访问 Google 地图，可自行替换为 OpenStreetMap 嵌入地址。
- 二维码库（`qrcode@1.5.3`）与图片裁切库（`cropperjs@1.6.2`）通过 jsDelivr CDN 引入；离线环境可把对应库下载到本地并改引用路径。
- 页面默认使用中性占位数据，不包含任何第三方品牌标识或外部账号信息。
